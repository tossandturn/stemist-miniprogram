# 安卓会员体验版准备与验收

日期：2026-10-28（Asia/Shanghai）。目标版本 1.0.63。

## 交付范围

在现有 1.0.62 登录修复基础上接入会员中心，复用已审付款协议，不替换旧整仓。入口为“我的 → 会员中心”；IELTS 原会员入口同步转入新页，激活码保留为次要入口。

首轮仅支持安卓虚拟支付，方案为 28.80 元 / 30 天 / 无自动续费。iOS、普通 `wx.requestPayment` 替代路径、全站收费和强制会员限制均未启用。真实付款必须本人在微信确认，工具测试没有支付、退款或订单写入生产。

## 安全与恢复

- 服务端决定价格、身份、商品、测试资格、订单与权益。未知或未开放状态不会下单。
- 体验/开发版仅展示、复制经服务端核验的本人 `ielts:<id>` 测试编号，正式版不展示诊断编号。
- 仅完全相同的 owner、privacy epoch、幂等 key 和订单可从明确取消状态继续付款；未知结果只查询。
- 单次前端成功回调不能开通会员；服务端确认后才更新权益。fulfilled 缺少权益时补查权威订单。
- 切换账号或隐私版本清除旧确认勾选和临时状态；迟到 code、checkout 响应和支付回调不污染新账号。
- 支付签名/参数不进入 storage、setData、日志或代码配置。
