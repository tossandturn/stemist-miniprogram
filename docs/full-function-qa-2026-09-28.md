## 本轮修复

- 登录：迟到响应不能覆盖另一个账号的 Cookie；异常 owner/token 响应在落盘前拒绝。
- 会话：401 保留草稿时保留旧 owner，即使旧版缺 session metadata；同账号恢复保留内容，其他账号成功登录后清理旧私有数据，真正 guest 不误删。
- 页面：听力、阅读、口语、笔记、Coach、裁剪页切账号后清除旧可见内容并拦截晚回包；拍照入口不继承上一账号的私有重拍路线。
- 作答：切换到 ABCD 清除旧照片/AI/自评引用，但保留客观题历史；重复批改明确显示正在处理，不再伪成功；整卷证据正确区分选择题、照片和混合，并忽略空答案。
- 音频：完整下载有独立停滞与总时间限制；新增强验证器约束的分块缓存、持久断点及取消/重试保护。源不支持安全续传时回退完整下载，不拼接不可靠字节。
- 包体：目录 bootstrap 无损压缩，148,473 → 92,408 bytes，完整内容、字段顺序和独立对象引用均验证不变；没有减少题目或放松 ready 门槛。
