# AI Coach 文案与布局精简

用户要求删除不必要的描述并优化排版。基于 1.0.82 的原生截图：功能卡说明、任务介绍以及多次 AI Coach 标题占据首屏，拍题输入与发送位置过低；任务入口还被原生按钮默认宽度压窄。

范围：原生 Coach 功能页、当前/旧学科答疑页、任务列表、申请/雅思顾问的欢迎区和酒馆的少量重复提示。仅改显示文案、层级和样式，不改 AI 提示词、请求参数、模型、任务保存规则、会员、支付或题库。

保留：三个中文模式且思考开启；深入/极致可选保存 3 天；真实上传/分析/生成进度、估时的不确定性、失败恢复、考试限制、AI/本地结果区别、出处按需识别、隐私/官方结果边界、相机/裁剪/多图证据、键盘与账号隔离。

布局：入口六卡只保留图标与名称，答疑任务用短按钮；问题页移除重复大标题和图片介绍，合并模式与思考状态；统一输入与发送区，只有发送为主要动作。回答继续按答案/步骤分模块，但减少嵌套卡片。顾问欢迎长段落删除，保留快捷开场和必要边界。

验证：先建立会失败的精简文案/结构测试；修改后运行任务、模式、公式、照片、角色/键盘、视觉、全套及打包回归。截图复核空白、图片、处理中、完整答案、失败/重试、保存任务、顾问欢迎与酒馆；核对手机按钮边界和首屏发送位置。保持 128 KiB 主包余量，不改后端。

参考微信官方 [WeUI FormPage](https://github.com/wechat-miniprogram/weui-miniprogram/blob/master/docs/form-page.md) 的内容/控件/提示/操作分层；[MIT 许可](https://github.com/wechat-miniprogram/weui-miniprogram/blob/master/LICENSE)。只参考模式，不复制或安装组件，沿用现有浅色紫系与原创图标。UI/UX 参考用于 44px 触点、8px 间距、可读字号、渐进披露和安全区。
