## 性能证据边界

未压缩字节数已减少约 93%，但 2026-09-06 当前工作站/DevTools 的两次完整
操作计时仍为约 7.9s/11.1s，包含网络与自动化动作；不能宣称体感卡顿已解决。
正在分别记录网络响应、页面载入、渲染、缓存命中，避免只用包大小解释性能。
Windows curl/Node 到站点存在 TLS/连接失败；服务器 loopback 请求成功。

后续实测：服务器侧同一试题请求约 5–7ms，工作站 DevTools 一次约 13.4s；
因此已增加本地版本化资料包。离线测试逐一读取全部 291 份任务，零数据接口
请求，Node 解码总耗时约 74–80ms（不是手机 FPS）。官方工具真实隔离账号
流程中，第 14–26 题工作区打开并可交互约 3.3s，含 CLI 调用开销。

真实评分已通过：自编答案返回 0/13，未显示整套 Band。随后查询云端记录为 0，
从而复现闭环缺口。`27cb626` 的 HTTP 回归已覆盖记录写入、重复提交、分段身份、
摘要/详情和跨账号 404；上线后须重跑 `test-native-real-submit.cjs --run-production`。
当前全套 `npm run test:all` 通过；真实相机/麦克风与完整模拟仍不能宣称通过。
