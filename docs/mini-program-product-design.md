这份文档是小程序实现的单一设计基线。它把 `STEM Studio` 与 `IELTSist` 已有的学习闭环、视觉语言和 AI Coach 边界迁移到微信小程序，而不是重新做一个独立 Demo。

说明：通用 UI 规则检索建议了偏游戏化的深色/粉色方案，但现有 STEM Studio 与 IELTSist 的生产 token、学生认知和跨站品牌一致性优先，因此本项目明确采用现有的浅色 `#f5f6fb` + `#7357e8` 体系，不引入另一套视觉品牌。

## 1. 产品定位

小程序是统一产品的轻量入口，首页展示六个一级入口：

`A-Level 学科 | IELTS | AP | IB | 竞赛 / 入学考试 | Casio 计算器`

未登录访客可以直接进入浏览和本机草稿模式，不在启动或点击入口时自动创建微信身份。静默调用仅刷新已有短期会话；真正调用 AI 或同步云端记录时再引导用户主动登录。AI Coach 是右上角固定入口，所有页面都能直接打开。

它不替代网页/iOS 的完整 PDF 工作区：

- STEM 在小程序中采用「一题一拍」，先进入原生后置相机取景页，再裁剪、AI Coach；没有相机能力的开发者工具才降级到仍限制为 `sourceType:['camera']` 的兼容调用，不打开相册。
- IELTS 入口映射 Dashboard、四项技能、Same‑Test、Random Exam、Vocabulary、Mine/Account、Subscription 和 AI Coach；全部在原生页面实现，不以外链补缺口。
- IELTS Listening / Reading 保留文本工作区，题库、音频、文章和证据链仍以 IELTSist 为准。
- Writing 使用真实题库和题图，支持文字或照片直接提交多模态批改；不要求先 OCR、转录或核对文字。文字稿与照片稿明确切换，照片模式不携带旧文字。批改异步执行，支持原生 PDF 报告；重写训练等剩余细节仍须按功能对照表完成验收。
- Speaking 使用原生录音、PCM WebSocket、WebAudio、对话和反馈；真机回声、长会话及双向录音导出尚未验收，不得宣称已完成。
- STEM Topic 原图按当前题加载并保留多页、图表及分问。整卷及竞赛共用原生逐题照片工作区；完整原卷通过微信原生文档查看器打开。

## 2. 信息架构

### 首页 Today

首页第一屏回答：学什么、从哪里进入、AI 在哪里。2026-10-30 按用户要求提升大学目录与学习账号入口优先级，不展示实现过程和连接检查：

1. 品牌栏：STEMist；AI Coach 固定在右上角。首页不强制登录；“我的”提供微信一键登录，已有会话可静默刷新。
   品牌栏之后首先展示公告中心，再展示学习入口；没有公告或预览加载失败时仍保留可点击入口，不伪造公告内容、数量或发布日期。
2. 公告下方先展示“大学排名与官网”“我的学习账号”两张醒目服务卡，再展示六张学习入口卡：A-Level 学科、IELTS、AP、IB、竞赛/入学考试、Casio 计算器。计算器免费，无需会员与登录、不占下载份数；其他远程次级链接保留，但不重复渲染大学目录入口。
3. 入口失败只显示可理解的恢复提示，不把内部 prompt、provider、路由调试词展示给学生。
4. A-Level 可选择学科和阶段，再进入章节、拍题、真题、模拟、进度或笔记。竞赛直接进入真题目录，只筛选考试和试卷，不展示 Topic readiness。
5. IELTS 按“开始学习 / 四项技能 / 整套模拟 / 词汇与账号”分组，不重复添加“完整工作区”和第二张 AI Coach 卡片。遗留站内链接转到对应原生页。
6. 进入工作区后不再重复放 A-Level/IELTS/竞赛三段筛选条，只显示“当前工作区 / 切换入口”；学科和阶段才是该页真正的筛选项。

### 账号登录与可选资料（2026-10-28）

所有显式登录入口统一进入账号页，以“微信一键登录”为主，保留“使用 IELTSist 账号”用于老账号恢复，不在小程序推广新用户名注册。访客可选择“暂不登录，返回浏览”；没有前一页或返回失败时回首页。登录中离开会取消本次客户端尝试，迟到的 code/HTTP 响应不能写入身份或弹出成功提示。旧密码登录同样必须在 cookie/token 写入前遵守取消与账号切换检查。

微信登录不等于头像昵称授权：不强制资料页、不自动读取头像、昵称、手机号；用户可从“我的”主动设置头像与昵称，读取失败、处理头像或保存中也能返回。页面退出后不再采纳迟到的资料响应，但不宣称撤销已在服务器完成的保存。

会员与学习记录绑定后端统一用户 ID，服务端验证微信 AppID/OpenID 后映射身份。缺少 UnionID 不阻断同一 OpenID 的正常登录。资料不是身份键，不能靠相同昵称合并账号；尚未绑定微信的旧密码账号仍需旧账号入口，未来绑定必须有双方身份验证。

### 会员体验测试（2026-10-28）

2026-10-29 更新：合入安卓与苹果独立订单平台和恢复指针。受控测试由各平台私有授权决定；正式购买由已登录账号的服务端目录、平台白名单与真实验收开关决定。iOS 检查微信版本与原生支付能力，不借安卓授权下单。支付确认前明确 28.80 元、30 天及非自动续费；同账号跨设备共享权益。结果不明只查原单；微信已使用的 outTradeNo 不可再次拉起支付。界面和模拟器通过不代表真实付款已验收。

“我的 → 会员中心”进入账号分包；原 IELTS 会员入口转入此页，激活码作为独立次要入口保留。本轮仅准备安卓体验测试，不开放苹果 IAP 或普通 JSAPI 替代通道。实际商品固定为 28.80 元、30 天、手动续费；确认框必须说明价格、期限、非自动续费及体验版也可能真实扣款。未登录、服务端未开放、测试窗口过期、平台不符或协议异常均不得创建订单或拉起支付。

测试资格由服务端按固定本人账号、最多两小时和单笔订单控制；前端不能自行指定资格。体验/开发版可复制从已验证 `/api/membership/status` 返回的本人账号编号，不能用微信开发者账号、昵称、OpenID 或本机猜测值代替。未确认测试账号前保持下单关闭；普通用户不启用收费或强制会员限制。

取消后先保留原订单核验状态，识别官方 errCode=-2，并兼容只返回取消文本的旧客户端回调。只有服务端核实旧订单已关闭，才能按新恢复标识生成关联的新订单号；不得复用微信 outTradeNo。未知、已拉起、已提交或已付款状态只查单，不重新付款。原生支付页返回前台但取消回调尚未到达时，不清除尚未完成的请求；迟到取消会刷新当前同账号页面，查单失败仍明确显示“已取消、待核验”，不假装支付仍在进行。关闭确认后自动刷新资格并清除旧同意勾选，新的付款仍需用户明确确认。用户离开、切换账号或隐私版本变更后，迟到结果不能拉起支付或更新新账号。原生支付成功只表示已返回，服务端核实订单并确认会员状态后才显示已开通；签名和支付参数不进入页面数据或本机存储。

体验版是分发渠道，不是沙箱支付的同义词。安卓真机付款、到账、退款与权益恢复另行验收；苹果端需单独确认 IAP 接入，不从安卓验收推断苹果可用。

### 技能工作区

每个工作区统一使用：

`Header → Context card → Input/evidence → AI Coach → Error/result → Next action`

共性由组件提供，技能页面只传入标题、上下文、占位文案、请求上下文和提交策略。AI Coach 不再使用页面内的开发者式提示词作为学生文案。

STEM 拍照在相机前必须选择 `subjectCode + stage`，对于 9709/9231 等存在多个纸张组合的路线还必须选择 `routeId`。客户端镜像 `src/data/routeRegistry.js` 的稳定路线 ID 并把它随照片传入 Coach，防止 Physics、Mathematics、IGCSE、A-Level 和 Competition 内容被错误合并。Writing 拍照使用独立的 IELTS 上下文，不复用 STEM 路由。

### STEM 类别边界

A‑Level 学科与竞赛/入学考试共用真题目录及 Coach 组件，但入口和服务端数据族严格分离。竞赛的用户入口仅保留真题：

- A‑Level 只允许 IGCSE、AS、A2 学科路线，发送 `category=alevel`、`family=exam`；
- 竞赛入口只允许 BPhO、AMC 12、ESAT、TMUA，Competition 与 Admissions 分别发送对应 `family`；
- `category + family + subjectCode + stage + routeId` 会随拍题、真题目录和网页接续传递，服务端仍是权限与成绩唯一权威；
- 切换入口会清空前一入口的路线和 inventory 状态，避免把题库数量或学习记录显示在错误类别下。

A-Level 章节摘要读取 `GET /api/stem/routes/{routeId}/syllabus-topics`，只展示当前章节与可用数量。后台保留来源和审核状态，但不把整组诊断指标堆给学生。竞赛不请求这个接口；整卷数量来自 QP 目录，不等同于 reviewed 题组数量。

2026-10-04：支持新库存契约时章节入口默认使用 `studyMode=chapter-study`，每章独立开练，题量按真实可用数量封顶。常规组卷与正式 6/12 门保留独立边界；空缺章使用明确标注的原创基础练习，原创不冒充真题、不计正式成绩或 READY。原题库存、练习来源、答题和记录保存使用同一服务端资格。验收范围见 `qa-2026-10-04-progress-chapter.md`。

## 4. 手机与 iPad 的明确适配

设备由 `utils/device.js` 读取 `deviceType`、型号和窗口宽度，页面得到 `device-phone` 或 `device-tablet` 类；CSS 只作为第二道保障。

### 手机（设备分类为 phone，不能仅按宽度判断）

- 阅读与输入内容单列，首页四入口为 2×2 网格；左右 16px 内边距。
- 底部固定五项导航：Today / Practice / AI Coach / Progress / Account；首页本身展示六个一级入口，不增加底部导航项。
- AI Coach 固定在右上角，不能被键盘、相机裁剪区或底部导航遮挡。
- 主按钮最小 44px 高，显式覆盖微信原生默认宽度，保证卡片间距至少 8px。
- 输入框和提交动作按垂直顺序排列，键盘弹出时不遮挡提交。
- STEM 裁剪区约 650rpx 高，优先拍单题。
- 口语为原生控制区和对话区，录音/音频在离开页面后立即停止。

### iPad（系统识别为 tablet/iPad，宽度仅作回退）

- 使用宽屏顶部导航，不显示手机底部导航。
- 首页不放指标说明；入口与技能卡根据 tablet 宽度排布。
- Listening/Reading/Writing/Coach 工作区采用左侧上下文 + 右侧输入/Coach 的双栏布局。
- STEM 裁剪区约 900rpx 高，横屏优先容纳题目和图表。
- iPad 竖屏自动改单栏，不能把两个栏压缩到不可读。
- 所有辅助面板必须保持在内容之外，不覆盖题目或输入区域。
- 裁剪使用 `movable-area scale-area` + `movable-view scale-value`，缩放和拖动事件都绑定在 `movable-view`；关闭惯性，保证图表/公式定位可重复。

## 5. AI Coach 数据链路

### AI Coach 功能入口

2026-11-01：界面名称统一为“快速 / 深入 / 极致”，三档均开启思考；学科默认快速。深入/极致可显式选择保存任务 3 天，普通即时答复不进入任务列表。下方历史记录中旧的英文档位及 24 小时保存仅描述旧版本兼容行为，不是新界面承诺。

同日精简：入口六卡只保留名称和图标，答疑任务为次要短入口。问题页不重复显示 AI Coach 大标题、图片区介绍和待机阶段的长说明；模式与思考状态合为一行，输入/发送为核心。答案和步骤继续分模块但降低嵌套卡片视觉层级。顾问欢迎段落改为快捷开场；保留 AI 身份、官方标准/隐私边界、真实进度、估时不确定性、保存期限和错误恢复。请求策略、图片证据、会员与服务端规则不变。

2026-10-31：学生可以选择思考强度“快速 · low / 深入 · high / 极致 · max”，用户已确认默认 low。控件复用于步骤提示、完整解答／检查作答、酒馆／抽取解读、申请顾问、雅思老师及整卷阅卷；独立 IELTS 学习批改与实时口语不受影响。当前账号和隐私版本绑定的选择可保存；新请求抓取一份档位快照，加载期间不能切换，失败重试／待保存收据沿用原档位。切档不自动发送；改档后的新请求不得复用旧档位结果。服务端只接受官方支持的三个值，显式选择不静默切到不支持该设置的模型，不展示隐藏思考文本。高档位等待和输出预算仍有上限，不保证一定更快或更准确。整卷任务在首次创建前保存档位，之后上传、重试和历史均保持该值；旧记录无该字段时继续使用原任务设置。

2026-10-30：大学排名的每个学校与 AP／IB／A-Level 课程官网卡片，均可进入原生“留学申请顾问”聊天。只带入页面上公开的名称、官网、榜单年份及来源，生成可编辑的提问建议；不自动发送、不伪称已实时浏览官网、不把名次当录取线。学校资料与课程考试规则、大学录取条件须分清。跳转使用短期、账号/隐私版本绑定的一次性引用，不在 URL 中放文书或个人资料。已有未发送草稿先保留，显式确认才替换，并可在本页恢复原草稿。游客从该页主动登录只继承明确选中的公开对象，切换到其他账号不得继承旧私有草稿。课程与大学数据仍由后台提供；新增的原生入口和布局需要客户端升级。

2026-10-27：保留原有四功能，新增第五项“留学申请顾问”和第六项“雅思老师”。两个原生入口独立于酒馆；兼容现有远程四卡配置，刷新配置不会隐藏新入口。申请顾问支持国际本科规划、背景分析、文书修改和申请邮件，首版为文字输入，不自动读取题目照片、作答记录或酒馆历史。独立云端对话按账号保存，可翻页、恢复和明确清空；本机只存隔离的草稿与重试标识，退出登录会清除。输入框复用已验证的键盘几何逻辑，流式部分内容不冒充完成结果。官方要求与 AI 建议分开，未核实的分数、截止日期、经历和录取概率不得编造；不声称真人中介或录取保证。
