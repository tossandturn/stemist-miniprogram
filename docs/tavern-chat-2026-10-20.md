# 星光酒馆：微信式聊天与键盘避让

日期：2026-10-20（Asia/Shanghai）。维护基线：`7ce53be86d251b734a2ce7778556082484444e49`。

## 本轮改变

- 会话使用左右消息气泡、角色头像、独立可滚动消息区和底部输入 / 发送栏。会话内不显示五项底部导航；“换角色”返回保留导航的选择页，微信原生返回路径不变。
- 输入栏参与 flex 布局，不再放在普通页面滚动内容底部。输入最多展示四行；更多内容在输入框内滚动。
- 同时处理键盘覆盖视口和 Android 窗口缩小：实际高度取 `min(当前窗口高度, 键盘打开前高度 - 键盘高度)`，不会重复扣减。关闭键盘、旋转、切后台和离开页面均处理监听生命周期。
- 低矮横屏键盘状态隐藏角色标题并把输入栏限制到一行，避免固定头部挤掉输入。点消息区可收起键盘；切角色、旋转不会丢失草稿。
- 最新消息在布局提交后测量滚动目标；历史浏览不强制跳到最新，旧角色的异步测量不能改变新角色视口。
- 普通发送和塔罗 / 卦签输入使用相同的键盘避让。原有账号隔离、历史分页、幂等重试、抽取和解读身份、考试限制不变。
- 清空操作增加确认，确认期间账号 / 角色变化时不会清空另一个会话。
- 原生富文本增加可选 `compact` 模式，仅酒馆使用，去掉空链接区和首末段多余空白；学术 Coach 默认排版、公式及安全链接处理不变。
