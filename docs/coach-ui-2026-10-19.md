## 原因与修复

1. 原生按钮默认宽度影响网格布局，原选择器未充分覆盖。四入口卡片和三帮助按钮现在使用明确的 scoped selector、border-box、width / max-width / min-width 限制。
2. 共享 Coach 面板的 rpx 字号和控件尺寸会随设备扩大。本轮改为稳定 px 规格，保持 44px 以上点击区域、小屏三列可读，以及平板独立布局。
3. 重复品牌、大标题和过高输入框占用首屏。改用已有紧凑标题，统一卡片圆角、留白、普通字重说明，输入框仍可滚动和正常输入。
4. 整卷批改的浮动栏与导航之间会露出被遮住的历史标题。改为贴合导航的全宽操作栏，保留页面滚动余量，历史末行可完整滚到操作栏上方。
5. “检查作答”选中时提交文案仍由入口 feature 决定。现在按照实际 helpIntent 显示对应动作。
6. 绘制 7 个轻量原创 SVG：四功能图标、Coach 星光，以及 PDF / 多图上传。只使用项目原生资源，不引入图片请求或组件依赖。
