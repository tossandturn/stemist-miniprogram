# 小程序修复验收 · 2026-09-05

本轮针对“竞赛只要真题、报错很多、排版和说明冗余”的反馈修复。

## 已复现并修复

1. 竞赛入口仍进入 Topic 工作区：现在直接进入真题目录，旧入口兼容重定向。
2. 竞赛筛选显示 Competition，实际按数组下标选中 IGCSE：竞赛取消不必要的阶段筛选，学科页按当前选项取值。
3. 试卷深链传 `subject`，STEM 实际读取 `course`：补齐 course、routeId、stage 和 past-paper-practice 模式。
4. 目录固定截断 80 份：改为每批 30 份，可继续加载全部匹配结果。
5. QP 的 pairKey 非空就被标成有答案：现在校验显式 markSchemeId、同组配对和答案文件的 active 状态。
6. 取消裁剪返回相机后 busy 未复位：可继续拍摄。
7. 作文拍照裁剪完成只返回两层，落到拍照设置页：按实际页面栈返回 Writing。
8. 输入后立即退出取消了保存定时器：退出时写入最后草稿；清空草稿则取消待写入内容。
9. Notebook 旧网络响应写进新路线，或覆盖正在编辑的笔记：绑定请求序号、路线、编辑版本和账号，保留未同步本机内容。
10. IELTS 请求携带 STEM token；IELTS 401 清理 STEM 会话：两个请求入口隔离认证头与清理行为。
11. 退出账号漏清 Coach 草稿与相机上下文：清理对应私有键并取消待写入的自动保存，防止退出后旧文字被写回。
12. 缺失题量 null 被转换成 0：保持未知状态。
13. 微信默认按钮宽度覆盖页面样式：提高关键样式的选择器优先级，实测卡片间距 12px，试卷按钮高度 44px。
14. app.json 的旋转和 permission 字段无效：旋转移入 window，移除不支持的相机/录音静态 permission 字段，保留运行时授权及隐私说明。
15. 计算器移植后数字键错行、小非零数被显示成 0：恢复四列数字键与小数科学计数显示。
16. WebView 加载失败时覆盖错误提示：失败移除 WebView，显示重试操作；异步回调不再写已离开的页面。
17. 口语页有独立 WebView，同样会挡住失败提示：失败卸载、重试重建地址，保留原技能参数。
18. 页面直接显示 navigateTo / 裁剪底层报错：改成简短的学生提示和具体恢复动作，不展示程序路径。
19. IELTS 菜单和输入框残留 Dashboard、examiner、证据链等措辞：改为学习动作；未提交的 Coach 不显示“反馈状态待确认”。

## 实际运行结果

通过微信开发者工具官方 SDK 连到当前小程序，运行 `node scripts/test-devtools-journeys.cjs`：8 段通过，0 个捕获到的运行异常。

- 首页四入口真实点击；390px 手机卡片间距 12px。
- BPhO 从生产读取 133 份真题；搜索 2024 得到 6 份，清空恢复 133 份。
- 考试选择器切到 ESAT，生产返回 16 份真题。
- 直接恢复 A2 Mathematics 的 P3 + S2 路线。
- IELTS 10 个去重后的功能入口，Reading 可打开。
- 计算器实际输入 `-2^2` 得到 `-4`；数字键尺寸约 81.7×44px。
- IELTS Coach 上下文正确，空输入被拒绝且无 loading 卡住。

相机取消/作文返回、草稿、Notebook 乱序响应、退出清理和 token 隔离由真实源码加载的行为回归覆盖，不依赖手写的替代业务实现。`npm run test:all` 含这些回归与 WXML/WXSS 编译。

行为回归目前共 14 项。额外文案契约检查真实 IELTS 功能目录，防止只删 WXML 的固定文字而遗漏数据驱动的说明。

## 本机测试环境与边界

- 开发者工具原自动化 CLI 的固定回调端口 3799 被 Windows 拒绝。临时启动脚本改用 OS 分配的空闲端口，安装文件未变；官方 SDK 使用 9420 自动化接口。
- 本机 `project.private.config.json` 仅设置 `setting.urlCheck=false` 供调试已知产品域名；该文件不提交。正式版仍须在微信公众平台配置 request / downloadFile / web-view 域名。
- 本轮图像来自开发者工具 iPhone 模拟器。iPad 分类与布局规则已回归，但不把手机截图或模拟器相机当成 iPad 真机、真实摄像头和麦克风的验收。
- 本轮未部署服务端，未改变题库的 reviewed 状态。
