# 酒馆回复中的表情包与图片

日期：2026-10-20。用户确认：不是页面装饰插图，而是 AI 消息内的表情包和配图；第一版使用原创图库，由 AI 选择，并要求图库足够大。

## 已实现

- 现有消息结构增加可选媒体，文字与媒体同一条消息保存、恢复、重放。旧纯文字记录兼容，旧客户端保存过的纯文字副本可以补全服务器原媒体。
- 客户端只发送能力版本，仍不上传图片 / 系统提示 / 学术上下文到酒馆。
- 严格校验素材 ID、固定服务路径、像素和图集坐标，不接受模型任意网址或 data URL。单条最多两份媒体。
- 文字、表情和配图原生显示。图片预留尺寸，按需加载；失败只显示图片重试，不清空文字；场景图可以点开预览，表情图集不会整张弹出。
- 保留键盘避让、草稿、账号隔离、历史分页、幂等重试、塔罗 / 卦签真实抽取与娱乐边界。媒体不是实际抽取结果的替代品。

## 图库与前后端分离

服务端首批 96 款表情＋12 张场景插画，共 108 个不同内容，使用 20 份原创图集 / 图片文件，总图片大小 2,900,611 bytes。原图由内置 image_gen 生成，完整提示词和来源哈希保存在后端素材 provenance；没有复制第三方素材。

完整图库不进入小程序包。以后新增素材按后台目录发布，客户端根据服务端媒体描述渲染，无需为单纯扩充图库重传开发版。现有素材 ID 和文件地址不可复用 / 删除，保证旧聊天的图片不变化。
