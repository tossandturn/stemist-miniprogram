# AI Coach 精简界面验收

日期：2026-11-01，Asia/Shanghai；仅客户端界面改动。

## 结果

- 功能入口移除重复介绍，保留六个名称与原创图标；“答疑任务”改为短入口。
- 答题页移除重复 AI Coach 大标题、图片区介绍和待机长说明。保留拍照、上传、裁剪、原图预览、上下文范围及清空。
- 模式和思考状态合为一行；“快速 / 深入 / 极致”、默认思考开启、深入/极致可选保存 3 天保持不变。
- 上传/分析/生成进度、真实字节与估时、失败/重试只在需要时显示。未保存的进行中请求不通过新增任务入口引导离开。
- 答案仍分答案/步骤，公式、表格和中英内容不改；步骤区去掉第二层卡片边框。出处识别仍由用户在答案完成后主动选择。
- 申请/雅思顾问的欢迎长段落删除，保留快捷开场、AI 身份、隐私与官方结果边界；酒馆保留人设、插图和娱乐提示。

没有更改服务端、AI 提示词、模型、会员购买范围、支付或下载规则。现网已开放的安卓/苹果购买不受本次影响。

## 验证

客户端运行提交：`591157091a9e167bce282acb6bba9bacc2c68aaa`。

PASS：`npm run test:all`，包括图片/裁剪/多图所有权、任务/断线恢复、三档选择、答案公式模块、角色与键盘、会员和下载回归，以及微信 WXML/WXSS 编译。

PASS：两次构建一致；21 项 Coach/基础模块打包测试和 26 项其他显式打包测试通过。构建层对 5 个现有 UI 支持模块做保留函数名的压缩，逻辑源码未改；主包余量保持 128 KiB 以上，没有降低预算门槛。

PASS：原生开发工具 11 项布局/交互状态验证，使用隔离存储及合成题目，不发起 AI 请求：

- 390 px 视口，六张功能卡片全部位于首屏；最后一张底部 496 px，导航顶部约 654.7 px。
- 空白答题页发送按钮底部 465.5 px；深入保存选项开启后为 521.5 px，均在导航上方。
- 保存选项触点高度 56 px，题图移除按钮 44 px；题图宽约 331.3 px，无横向溢出。
- 分析状态无伪造百分比；错误/重试保留问题文本。
- 答案和步骤模块及公式滚动容器实际渲染；截图确认步骤为平面分段，非嵌套卡片。
- 当前与旧拍题入口都使用精简面板；放大预览仍绑定完整图片。
- 顾问快捷开场和必要提示可见，模型请求数 0，运行错误数 0。

测试后原会话/存储已恢复，只清理本次生成的题目副本。原生自动化不支持用自定义标签查找组件，已添加稳定答案组件 ID；样式字段查询的克隆限制由布局几何和实际截图复核替代，没有改业务逻辑绕过测试。

## 边界

- 原生几何证据为开发工具 390 px。手机/平板横竖屏分类和布局契约测试通过，但未进行物理 Android/iPhone/iPad、相机、键盘、Apple Pencil、最大系统字号或深色主题验收；项目继续使用现有浅色主题。
- 本任务不重新验证 AI 生成质量或延迟，不把合成答案截图当成一次真实 AI 推理。
- 独立检出未复制真实题库，本地真题内容审计按既有脚本跳过；未改题库内容。
- 开发版本上传不等于体验版指定、提交审核或正式发布。
